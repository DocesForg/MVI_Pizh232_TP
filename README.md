# Quick Payment Widget (Android)

Демо-проект Android (Kotlin), который показывает предстоящие повторяющиеся платежи и добавляет виджет **«Быстрый платёж»** на домашний экран.

## Что реализовано
- Экран **предстоящих платежей** с загрузкой данных через Retrofit API (`GET /payments/upcoming`).
- **Офлайн-режим**: если сеть/API недоступны — используется кэш из `SharedPreferences`, иначе встроенный демо-список.
- Экран **формы оплаты** с предзаполненными полями.
- Виджет **Quick Payment**:
  - показывает до 3 ближайших платежей;
  - по нажатию открывает приложение сразу с формой оплаты;
  - префилл передаётся через `Intent` и хранится в `SharedPreferences`;
  - обновляется после загрузки и после добавления пользовательского платежа.
- Простая навигация между экраном списка и экраном оплаты (Jetpack Navigation Compose).
- Обновленный Material 3 дизайн карточек/форм и адаптация под светлую/тёмную тему устройства.
- Добавление собственных платежей прямо на главном экране (название, счет, сумма, дата).
- Сумма поддерживает дробную часть через запятую (например `1200,50`), дата выбирается из календаря.
- Скрытие платежей в виджете (повторное добавление происходит автоматически по кнопке **«Оплатить»** в списке приложения).
- Удаление платежей из списка приложения.

## Стек
- Kotlin
- Jetpack Compose
- Navigation Compose
- Retrofit + OkHttp
- SharedPreferences (кэш + префилл для виджета)

## Запуск
1. Открыть проект в Android Studio (JDK 17).
2. Дождаться Gradle Sync.
3. Запустить `app` на эмуляторе/устройстве (Android 8.0+).
4. Добавить виджет **Quick Payment** на домашний экран.

## Проверка сценария задания
1. Откройте приложение и убедитесь, что виден список платежей.
2. Нажмите **Оплатить** на любом элементе.
3. Вернитесь на домашний экран, добавьте виджет.
4. Нажмите на виджет — откроется форма оплаты с предзаполненными значениями.

## Примечание по API
В проекте указан демонстрационный `BASE_URL` (`https://demo.payments.local/`).
Если API недоступен, проект автоматически работает в офлайн-режиме на кэше/демо-данных.
